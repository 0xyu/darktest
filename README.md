# Dark Fantasy Grid RPG

## Project Status

Prototype / MVP development.

## Concept

A 2D dark-fantasy RPG built around grid-based, turn-based combat and highly satisfying loot progression.

The primary gameplay loop is:

```text
Fight
→ Loot
→ Compare
→ Equip
→ Become Stronger
→ Push Higher Stages
→ Find Better Loot
```

The main player fantasy is discovering a powerful item that creates a noticeable jump in character power.

## Core Features

- Grid-based movement
- Turn-based combat
- Player movement + one action per turn
- Random enemy encounters
- Stage-based progression
- Enemy level variance around the current stage
- Mini Boss every 10 stages
- Random special encounters
- Equipment rarity and random affixes
- Build-defining unique item effects
- EXP and level progression
- Gold progression
- Auto combat
- Dark fantasy / Gothic ARPG-inspired UI

## Design Philosophy

The game should combine:

- The readable grid combat of a turn-based RPG
- The loot excitement of a Diablo-like ARPG
- The continuous exponential progression philosophy of Clicker Heroes
- The convenience of auto combat / idle-friendly progression

The game should be easy to understand while gradually becoming deeper through equipment builds.
